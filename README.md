# Rihan Naseer — Developer Portfolio

A responsive portfolio built with Next.js and TypeScript, based on the resume supplied for Rihan Naseer.

## Run locally

Install Node.js LTS, then run:

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

- Verify that the resume details and dates are accurate.
- LinkedIn is not included because no personal LinkedIn URL was present in the resume.
- Add a resume PDF link if you want visitors to download your CV.
- Only link public project repositories or demos that you are allowed to share. Do not publish confidential company code or credentials.

## Deploy

Push this folder to a new GitHub repository and import it at https://vercel.com/. Deploy the project and use the actual URL provided by Vercel in your resume.
